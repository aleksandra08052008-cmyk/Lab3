## Опис завдання

У даній лабораторній роботі необхідно:
- створити клас "Cosmetic" з не менше ніж 5 полями;
- створити масив об’єктів цього класу;
- відсортувати масив за одним полем за зростанням, а за іншим — за спаданням;
- знайти в масиві об’єкт, який ідентичний заданому;
- реалізувати модульні тести для перевірки роботи програми.
   
## Опис реалізації
У програмі створено клас "Cosmetic", який містить такі поля:
- name (назва)
- brand (бренд)
- price (ціна)
- volume (об’єм)
- rating (рейтинг)

У виконавчому класі створюється масив об’єктів "Cosmetic".
Сортування виконується методом "Arrays.sort()":
- price — за зростанням
- rating — за спаданням (як другорядний критерій)

Пошук об’єкта здійснюється за допомогою циклу "for" та методу "equals()".
